完整端点与调用契约

所有业务请求使用 JSON；API Key 放在 Authorization 请求头，不要放入 URL

GET/open-api/v1/healthREAD 鉴权与存活检测
GET/open-api/v1/devicesREAD 脱敏设备列表
GET/open-api/v1/channels?offset=0&limit=30&q=READ 通道分页，limit 最大 100
GET/open-api/v1/devices/{deviceId}/snapshot?channelId=...PLAYBACK 串行抽帧，优先复用直播
POST/open-api/v1/devices/{deviceId}/playPLAYBACK Body: channelId, streamType
POST.../play/{playbackId}/heartbeatPLAYBACK 维持点播会话
POST.../play/{playbackId}/stopPLAYBACK 主动释放摄像机与媒体资源
POST/open-api/v1/devices/{deviceId}/ptzCONTROL Body: channelId, action, speed
GET/api/playbacks/{playbackId}/media/{file}PLAYBACK HLS 清单与分片，需双请求头
HTTP可直接使用，但 API Key 会以明文经过网络，仅建议内网或 VPN。
HTTPS生产环境推荐通过 Nginx/网关终止 TLS，并传递 X-Forwarded-Proto/Host。
CORS服务器间调用不受 CORS 影响；浏览器跨域需配置 OPEN_API_ALLOWED_ORIGINS。
状态码401 密钥无效；403 权限不足；429 超限；400 参数或设备状态错误。
